# MASTER AI PROMPT - COUPONTRUST GLOBAL COUPON MARKETPLACE

Create a complete production-ready MERN Stack application called **CouponTrust**.

## PROJECT VISION

CouponTrust is a global AI-powered coupon marketplace where users can buy and sell unused coupons.

Unlike traditional coupon marketplaces:

* No manual coupon approval.
* AI verification is the approval system.
* AI verifies coupon screenshots and compares them with user-entered data.
* If AI verification passes, the coupon is instantly listed.
* If AI verification fails, the coupon is rejected automatically.
* Trust score system protects buyers from fraud.
* Stripe escrow-style payment system protects buyers and sellers.

The system should support millions of users globally.
