Create a full MERN stack project named CouponTrust.

PROJECT OVERVIEW:
CouponTrust is a global coupon buy and sell marketplace where one normal user can both buy coupons and sell coupons, similar to Instagram where a user can view reels and also create reels.

Users can:
1. Register/login using mobile OTP with Twilio.
2. Browse verified coupons.
3. Buy coupons using Stripe.
4. Sell unused coupons.
5. Upload coupon screenshot proof.
6. Get AI verification before coupon submission.
7. Track bought coupons, sold coupons, wallet, disputes, trust score.
8. Receive mobile SMS notifications.

Admin can:
1. Manage all users.
2. Review all coupons.
3. View AI verification results.
4. Approve/reject coupons.
5. Handle payments.
6. Handle escrow transactions.
7. Resolve disputes.
8. Refund buyers.
9. Release seller payments.
10. Ban users when trust score is below 60.

USER FLOW:
1. User opens app.
2. User enters mobile number.
3. Backend sends OTP using Twilio.
4. User verifies OTP.
5. User enters dashboard.
6. User can browse coupons.
7. User can buy coupon.
8. User can also sell coupon from Sell tab.

SELL COUPON FLOW:
1. User clicks Sell Coupon.
2. Show safety popup:
   - Upload only real coupon.
   - Screenshot proof is compulsory.
   - Fake coupon reduces trust score.
   - Trust below 60 causes account ban.
   - Duplicate/expired/edited coupons are not allowed.
3. User accepts rules.
4. User fills coupon form:
   - Platform name
   - Coupon title
   - Coupon code
   - Coupon value
   - Selling price
   - Expiry date
   - Terms and conditions
   - Coupon screenshot proof
5. Backend stores screenshot locally using Multer.
6. Backend sends screenshot to AI/OCR service.
7. AI extracts:
   - Platform
   - Coupon code
   - Value
   - Expiry date
   - Terms
8. Backend compares user input with AI extracted data.
9. If match score >= 85:
   - Save coupon as pending_admin_review.
10. If match score < 85:
   - Do not create public coupon.
   - Return error: Coupon details do not match screenshot.
   - Add suspicious upload count.
11. If user has 3 AI mismatches in 30 days:
   - Deduct 10 trust score.
12. If trust score below 60:
   - accountStatus = banned.

BUY COUPON FLOW:
1. User opens coupon marketplace feed.
2. User filters by platform, country, discount, price, expiry.
3. User opens coupon details.
4. User clicks Buy Now.
5. Backend creates transaction.
6. Backend creates Stripe PaymentIntent with capture_method manual.
7. Frontend completes Stripe payment.
8. Backend verifies payment authorization.
9. Coupon code is revealed to buyer.
10. Transaction status becomes coupon_revealed.
11. Buyer clicks Coupon Worked.
12. Backend captures Stripe payment.
13. Platform commission deducted.
14. Seller wallet credited.
15. Transaction completed.

DISPUTE FLOW:
1. Buyer clicks Coupon Not Working.
2. Buyer adds reason and proof.
3. Transaction status becomes disputed.
4. Admin reviews:
   - Buyer complaint
   - Seller details
   - Coupon screenshot
   - AI extracted data
   - Payment data
5. Admin decision:
   A. Refund buyer:
      - Cancel/refund payment
      - Deduct seller trust score
      - Mark coupon fake if confirmed
   B. Release payment to seller:
      - Capture Stripe payment
      - Credit seller wallet
6. Fake coupon confirmed:
   - Deduct 20 trust score.
   - Increase fakeCouponCount.
   - If trustScore < 60, ban account.

TRUST SCORE RULES:
Every user starts with:
trustScore = 100
accountStatus = active

Rules:
- AI mismatch once: warning only
- 3 AI mismatches in 30 days: -10
- Fake coupon confirmed: -20
- Duplicate coupon: -15
- Expired coupon uploaded: -10
- Buyer refund due to seller fault: -20
- Trust score 100-80 = Excellent
- Trust score 79-60 = Warning
- Trust score below 60 = Banned

Banned users cannot:
- Sell coupons
- Buy coupons
- Withdraw wallet balance
- Create disputes except support ticket

REVENUE MODEL:
1. Platform commission per sale:
   - 10% default commission.
   Example:
   Coupon selling price = ₹100
   Platform commission = ₹10
   Seller earning = ₹90

2. Featured coupon listing:
   Sellers can pay to promote coupons.

3. Seller subscription:
   Free plan: 10 active listings/month
   Pro plan: unlimited listings + featured boost

4. Withdrawal fee:
   Small fee on seller wallet withdrawal.

5. Brand partnership:
   Brands can list official coupon campaigns.

PAYMENT ESCROW LOGIC:
Use Stripe PaymentIntent manual capture.
When buyer buys coupon:
1. Create PaymentIntent with capture_method manual.
2. Confirm payment on frontend.
3. Backend checks status.
4. If authorized, reveal coupon.
5. If buyer confirms coupon worked, capture PaymentIntent.
6. Credit seller wallet after platform commission.
7. If disputed, do not capture until admin decision.
8. If admin refunds buyer, cancel/refund PaymentIntent.
