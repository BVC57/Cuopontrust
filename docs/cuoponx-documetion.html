18. Sell Coupon Flow

1. User clicks "Sell Coupon"
2. Safety popup — accept rules
3. Fill coupon form
4. Upload screenshot (Multer)
5. AI/OCR extracts data
✅ Pass ≥ 85% → Coupon listed instantly
❌ Fail < 85% → Coupon rejected, suspicious count++

19. Buy Coupon Flow

1. Browse marketplace feed
2. Filter by platform, country, price
3. Open coupon details
4. Click "Buy Now"
5. Create PaymentIntent (manual capture)
6. Complete Stripe payment
7. Coupon code revealed
✅ Coupon Worked → Capture → Commission → Seller credited

20. Dispute Flow

1. Buyer clicks "Coupon Not Working"
2. Add reason and proof screenshot
3. Transaction → disputed, payment held
4. Admin reviews all evidence
✅ Refund Buyer → Cancel payment, deduct seller trust
✅ Release Seller → Capture payment, credit seller
⚠️ Fake Coupon → -20 trust score, if below 60 → banned

21. Security Implementation

🔒 Security Measures
  • JWT: Access (1h) + Refresh (7d)
  • AES: Coupon code encryption
  • Rate Limiting: 100 req/min
  • Helmet: Security headers
  • CORS: Whitelisted origins
  • Validation: Joi/Zod
  • File Validation: Images only, max 5MB
  • Sanitization: Input sanitization
🛡️ Middleware
  • auth.middleware: JWT verification
  • admin.middleware: RBAC
  • banned.middleware: Block banned users
  • upload.middleware: Multer handling
  • error.middleware: Global error handler
